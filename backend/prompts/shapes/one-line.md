---
name: one-line
description: A cold message to a person, one line and a link. Use for any ping, notification, or reply nobody asked to be long.
---
One line. A link if there is one. Quote people by name and colon:
`Peter: ok dns is ready on my side ↗`.

No greeting, no sign-off, no summary of what the agent did, no emoji.
If it needs two lines it is not crystallized yet. If it needs more, it is a
`map`: send the top line and the map's link.
